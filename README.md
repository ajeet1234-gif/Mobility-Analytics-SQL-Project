# 🚖 Mobility Analytics SQL Project

## 📌 Project Overview

This project demonstrates the design and analysis of a **Mobility Analytics** database using **MySQL**. It includes database creation, table relationships, data import, and analytical SQL queries to generate meaningful business insights.

The primary objective of this project is to showcase practical SQL skills commonly required for **Data Analyst**, **Business Intelligence**, and **SQL Developer** roles.

---

## 🛠️ Tech Stack

* **Database:** MySQL
* **Tool:** MySQL Workbench
* **Language:** SQL
